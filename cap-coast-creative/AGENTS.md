# Project Instructions (Codex)

This repository is the dedicated home for **Cap Coast Creative**: the agency website, supervised CEO/growth engine, councils, safety rules, approval gates, prospect research memory, and operating dashboards.

The old parent workspace may still contain mock client sites and generated website ideas. Treat this repo as the source of truth for the Cap Coast Creative business engine and agency site.

## Operating Brain

This repo uses the **agentic-stack** portable brain layout. All memory, skills, commands, and protocols live in `.agent/`.

Before changing business-engine behavior, read:

- `.agent/AGENTS.md`
- `.agent/memory/personal/PREFERENCES.md`
- `.agent/memory/semantic/LESSONS.md`
- `.agent/protocols/permissions.md`
- `.agent/protocols/outreach-safety.md`

## Safety Boundary

Research, scoring, local planning, local drafts, local dashboards, and local private concepts are allowed when they follow `.agent/protocols/permissions.md`.

Do not send outreach, submit forms, DM, email, call, publish, bill, change domains/hosting, or create remote GitHub/Vercel changes without explicit Daniel approval for that specific action.
