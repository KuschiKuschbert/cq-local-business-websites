# `/source-quality-map`

Run `python3 .agent/skills/growth-engine/scripts/generate-source-quality-map.py` to generate higher-quality public source routes for prospect research.

This command turns broad search failures into safer targeted searches by preferring public directories, Facebook public-page searches, and business-profile-style results. It does not browse, scrape, contact businesses, promote prospects, or update third-party systems.
