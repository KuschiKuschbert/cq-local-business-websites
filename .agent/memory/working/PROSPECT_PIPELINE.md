# Prospect Pipeline

Stages: research, qualified, briefed, mockup-needed, mockup-ready, walk-in-planned, follow-up-draft, contacted, replied, meeting, won, lost, do-not-contact.

Weekly rhythm: research, verify evidence, generate private opportunity briefs, queue approvals, promote only with Daniel approval, generate mockup/outreach/proposal drafts only where eligible, log outcomes, review KPIs.

Promotion into `prospects.csv` is not outreach approval.
