# `/weekly-plan`

Run `python3 .agent/skills/growth-engine/scripts/generate-weekly-plan.py` to create the supervised weekly execution plan for the web design business engine.

The plan turns source lanes, research tasks, priority items, private concepts, approvals, and drafts into a Monday-to-Friday operating rhythm. It is planning-only and does not promote prospects, create GitHub issues, publish concepts, or send outreach.
