# `/pre-send-readiness`

Run `python3 .agent/skills/growth-engine/scripts/generate-pre-send-readiness.py` to audit whether any approved prospect is ready for manual outreach review.

This command is a red-light/green-light audit only. It never sends, schedules, queues, approves, or posts outreach. Sending still requires Daniel to approve the exact recipient, channel, copy, sender identity, contact basis, and opt-out path.
