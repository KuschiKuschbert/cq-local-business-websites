# `/council-ceo-brief`

Run `python3 .agent/skills/growth-engine/scripts/generate-council-ceo-brief.py` to turn current council debates into a ranked CEO boardroom brief.

The brief summarizes the strongest argument, strongest objection, uncomfortable truth, allowed next move, blocked actions, Daniel decision required, and evidence path for each council decision. It is advisory only and cannot approve promotion, outreach, publishing, remote GitHub writes, billing, or client-facing actions.
